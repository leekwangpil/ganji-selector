# 자연순환 사건·절기 GPT 연결

1. 이 변경을 배포한 뒤 `https://ganji-selector.vercel.app/openapi.json`이 열리는지 확인합니다.
2. GPT 편집기에서 웹 검색을 활성화합니다.
3. Instructions에 `docs/gpt-instructions.txt` 내용을 붙여 넣습니다.
4. Actions에서 위 OpenAPI URL을 가져옵니다. 인증은 None입니다. 이 API는 입력을 저장하지 않는 공개 계산기입니다.
5. 이름·조회 기간과 확인된 생년월일·성별·출생 시간대·계산 기준으로 테스트합니다.

년운·월운은 기존 엔진의 절입 경계와 기간 중간점 규칙을 사용합니다. 해석과 사건 수집은 API에 없습니다. GPT가 검색한 출처로 사건을 정리합니다. 1910년 시작은 기존 엔진의 UTC 범위 제한으로 제외합니다. 1회 최대 20년입니다.

GPT 대화에서 추가한 지침은 새 대화에 영구 반영된다고 가정하지 마세요. 지속 적용할 규칙은 편집기의 Instructions를 수정합니다.
